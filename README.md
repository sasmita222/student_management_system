# Student Management System (C Project)
This project is a simple Student Management System developed in the C programming language, designed specifically for beginners and first-year B.Tech CSE students. The program offers basic functionalities to manage student records efficiently through a console-based interface. Users can add new student details, including roll number, name, and marks, and display all the stored records in a clear and organized manner.

The main focus of this project is to help beginners understand core C programming concepts such as structures (to hold student data), arrays (to store multiple records), loops (for repetitive tasks), and conditional statements (to handle choices and validations). It also demonstrates how to take input from users, perform simple data management operations, and display output neatly.

This project is a foundation for learning data management and can be extended easily with additional features such as searching students by roll number, updating records, deleting entries, and saving data to files. It encourages modular programming and provides practical experience with fundamental coding techniques.
## Features
- Add new student records (name, roll number, marks, and other details)
- Display all stored student information
- Search for a student by roll number
- Update existing student details
- Delete student records
- Store data in a file for permanent record keeping

## Technologies Used
- Language: C
- Concepts: File handling, Structures, Functions, Loops, and Conditional Statements
- Platform: Windows/Linux (gcc compatible)

## How to Run
1. Clone this repository:git clone https://github.com/sasmita222/student_management_system.git
2. Open the project folder.
3. Compile the code using a C compiler (e.g., gcc):
gcc student_management.c -o student_management
4. Run the executable: ./student_management
